GBF-Resize
==========

グランブルーファンタジー(GBF)を、ブラウザのアプリウィンドウ(アドレスバーのない窓)で開き、
あらかじめ記録しておいた位置と大きさに並べる Windows 用のツールです。

※ 非公式のツールです。株式会社 Cygames およびグランブルーファンタジーとは一切関係ありません。
   問い合わせを公式にしないでください。

このツールは、ブラウザの窓の位置と大きさを変えるだけです。
ゲームの通信や画面の中身には一切触れず、自動操作や表示を変える機能もありません。


■ 必要なもの

- Windows 10 / 11
- Chrome、Edge などの Chromium 系のブラウザ(Firefox は使えません)


■ 起動のしかた

1. このフォルダを、「ドキュメント」の中など自分のフォルダに置きます。
   設定はこのフォルダの GBF.ini に保存されるので、C:\Program Files の中では動きません。
2. GBF.exe をダブルクリックすると、設定画面が開きます。

初めて起動するときに、青い画面で「Windows によって PC が保護されました」と出ることがあります。
これは、署名をしていない、まだ使う人の少ないアプリに出る表示です。
「詳細情報」を押すと出てくる「実行」を押せば起動できます。2回目からは出ません。


■ 使い方

1. 「ブラウザ」で使うブラウザを選びます。
   GBF にログインしているのが既定以外のプロファイルなら、「プロファイル」にその名前(Profile 1 など)を入れます。
2. 「窓の数」(1〜3)を選び、「起動して試す」を押します。その数だけ GBF が開きます。
3. 好きな位置・大きさに直し、「今の配置を記録」を押します。
   数 px の隙間や上端のずれは自動で詰めます。
4. 「デスクトップにショートカットを作成」を押します。以後は次の2つを使います。

   GBF 起動 (N窓)   GBF を N 個開いて、記録した場所に並べる
   GBF 並べ直し      開いている GBF の窓を、記録した場所に戻す

配置は窓の数ごとに記録されます。1窓と3窓を使い分けるなら、それぞれの数で 2〜4 を行ってください。

設定画面を閉じるとき、「起動して試す」で開いた GBF の窓が残っていれば、閉じるかどうかを聞きます。
その窓でそのまま遊ぶなら「いいえ」を選んでください。

このフォルダを移動したら、ショートカットを作り直してください。


■ 使うのをやめるとき

このフォルダと、デスクトップのショートカット(GBF 起動・GBF 並べ直し)を削除してください。
レジストリなど、ほかの場所には何も書き込んでいません。
