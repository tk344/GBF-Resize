# GBF-Resize

グランブルーファンタジー(GBF)を、Chrome や Edge などのアプリウィンドウ(アドレスバーのない窓)で開き、
あらかじめ記録しておいた位置と大きさに並べる Windows 用のツールです。
複数の窓を横に並べて遊ぶときに、毎回手で並べ直す手間を省けます。

> **非公式のツールです。** 株式会社 Cygames およびグランブルーファンタジーとは一切関係ありません。
> 問い合わせを公式にしないでください。

## このツールがすること・しないこと

- **すること**: ブラウザを `--app=<URL>` で起動し、Windows の機能で窓の位置と大きさを変えます
- **しないこと**: ゲームの通信、画面の中身、ページの内容には一切触れません。
  自動操作や、表示の改変(CSS の差し込みなど)の機能もありません。今後も入れません

扱うのは窓の外側だけです。ブラウザの窓を手で動かすのと同じことを、記録した値で行います。

## 必要なもの

- Windows 10 / 11
- Chromium 系のブラウザ(Chrome、Edge、Iron、Brave、Vivaldi など)。Firefox は `--app` モードがないので使えません

インストールは不要です。

## ダウンロード

1. [最新版のページ(Releases)](https://github.com/tk344/GBF-Resize/releases/latest) を開きます
2. ページ下の「Assets」にある `GBF-Resize-v〇〇.zip` をクリックして保存します
3. 保存した zip を右クリックし、「すべて展開」を選びます。
   展開先は「ドキュメント」の中など、自分のフォルダにしてください。
   設定は `GBF.exe` と同じフォルダに保存されるので、`C:\Program Files` の中では動きません
4. 展開したフォルダの `GBF.exe` をダブルクリックします

初めて起動するときに、青い画面で「Windows によって PC が保護されました」と出ることがあります。
これは、署名をしていない、まだ使う人の少ないアプリに出る表示です。
「詳細情報」を押すと出てくる「実行」を押せば起動できます。2回目からは出ません。

> この `GBF.exe` は、このリポジトリで公開しているソースから、GitHub の上(GitHub Actions)でビルドしたものです。
> 作者の PC でビルドしたものではありません。ビルドの記録は [Actions](https://github.com/tk344/GBF-Resize/actions) で誰でも見られます。
> 自分でビルドしたい場合は「[自分でビルドする](#自分でビルドする)」を見てください。

## 使い方

1. `GBF.exe` をダブルクリックして設定画面を開きます
2. 「ブラウザ」で使うブラウザを選びます(インストールされている Chromium 系のブラウザが一覧に出ます)。
   GBF にログインしているプロファイルが既定のもの以外なら、「プロファイル」にその名前(`Profile 1` など)を入れます
3. 「窓の数」(1〜3)を選び、「起動して試す」を押します。その数だけ GBF が開きます。
   まだ記録していない数なら、メインモニターの左上から横に並べて開きます
4. 好きな位置・大きさに直し、「今の配置を記録」を押します。上端の数 px のずれや、窓どうしの数 px の隙間は自動で詰めます
5. 「デスクトップにショートカットを作成」を押します。以後は次の2つを使います

| ショートカット | 内容 |
|---|---|
| GBF 起動 (N窓) | GBF を N 個開き、記録した場所に並べる(`GBF.exe launch N`) |
| GBF 並べ直し | 開いている GBF の窓を、その数の窓で記録した場所に戻す(`GBF.exe resize`) |

配置は窓の数ごとに別々に記録されます。1窓と3窓を使い分けるなら、それぞれの数で 3〜5 を行えば、
「GBF 起動 (1窓)」「GBF 起動 (3窓)」のようにショートカットが増えます。「GBF 並べ直し」は1つで全部の数に使えます。

設定画面を閉じるとき、「起動して試す」で開いた GBF の窓が残っていれば、閉じるかどうかを聞きます。
その窓でそのまま遊ぶなら「いいえ」を選んでください。

`GBF.exe` のフォルダを移動したら、ショートカットを作り直してください。

## コマンド

| コマンド | 内容 |
|---|---|
| `GBF.exe` | 設定画面を開く |
| `GBF.exe launch [N]` | GBF を N 個開いて、N 窓の配置に並べる。N を省くと `count` の数。記録がなければ左上から横に並べる。起動前から開いている GBF の窓には触らない |
| `GBF.exe resize` | 開いている GBF の窓を、左にあるものから順に、その数の窓の配置へ戻す。その数の記録がなければ、それより多い数の配置の左側を使う |
| `GBF.exe record` | 開いている GBF の窓(3個まで)を、左から順にその数の窓の配置として記録する |

`launch` に `--log <ファイル>` を付けると、窓を置いた・直したタイミングを書き出します(動作確認用)。

### 起動直後の補正について

GBF のページは、読み込み中に自分で窓の大きさを変えることがあります。そのため `launch` は、
最後の窓を置いてから15秒間(全体で最長60秒)見張り、大きさがずれたら直します。
この間に手で窓の大きさを変えた場合(端をドラッグするなど)は、その大きさを優先し、その窓は戻しません。

## 設定ファイル(GBF.ini)

`GBF.exe` と同じフォルダの `GBF.ini` に保存されます。設定画面で編集できますが、手で書き換えてもかまいません。
ファイルがないときは、初めて設定画面を閉じたときに作られます。

```ini
browser = C:\Program Files\Google\Chrome\Application\chrome.exe
profile = Default
url = https://game.granbluefantasy.jp/#mypage
title = グランブルーファンタジー
count = 2
layout1 = 100, 15, 380, 800
layout2 = -800, 15, 380, 800 | -434, 15, 380, 800
```

| キー | 内容 |
|---|---|
| `browser` | ブラウザの exe |
| `profile` | ブラウザのプロファイル(`--profile-directory` に渡す)。空欄なら指定しない |
| `url` | 開く URL |
| `title` | GBF の窓とみなす窓のタイトル。完全一致で、`\|` で区切って複数書ける |
| `count` | 窓の数を指定せずに `launch` したときに開く数(設定画面で最後に選んだ数) |
| `layoutN` | N 窓で使うときの配置。窓ごとの 左上 x, 左上 y, 幅, 高さ を、左の窓から順に `\|` で区切って並べる。物理ピクセルで、見えない枠を含む外側の大きさ |

ゲームの言語を英語にしている場合など、窓のタイトルが「グランブルーファンタジー」でないときは、
`title` を実際のタイトルに合わせてください。

## 使うのをやめるとき

`GBF.exe` のフォルダと、デスクトップのショートカット(GBF 起動・GBF 並べ直し)を削除してください。
レジストリなど、ほかの場所には何も書き込んでいません。

## 自分でビルドする

配布している exe を使わずに、自分でビルドすることもできます。

1. このページ上の「Code」→「Download ZIP」でソースを保存し、展開します
2. 展開したフォルダの `build.cmd` をダブルクリックします。同じフォルダに `GBF.exe` ができます

Windows に最初から入っている .NET Framework 4.x の C# コンパイラを使うので、追加のインストールは必要ありません。

配布している exe が、このソースからビルドされたものかを確かめたい場合は、
[GitHub CLI](https://cli.github.com/) で次のように確かめられます。

```
gh attestation verify GBF.exe --repo tk344/GBF-Resize
```

## 確かめてある環境・まだの環境

- 確かめてある: Windows 11、Chrome、Iron。Edge は、窓のクラス名とタイトルが Chrome と同じで、見分けられることまで
- まだ: Brave、Vivaldi、DMM 版、ゲームの言語が英語のとき

うまく動いた・動かなかった環境があれば、Issue で教えてもらえると助かります。

## 仕組み

- 窓は `EnumWindows` で探します。クラス名が `Chrome_WidgetWin_1` で、タイトルが `title` と完全に一致し、
  表示されていて最小化されていないものが対象です
- 座標と大きさは物理ピクセルで扱います(スレッドを Per-Monitor V2 にしています)。
  表示スケールが 100% 以外のモニターでも、記録した値のまま戻せます
- Windows 10/11 の窓には、左右と下に見えない枠があります。`record` で隙間を詰めるときは、
  `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)` で見た目の枠を取り、枠どうしが接するようにします
- 窓を動かすときは、重なり順やフォーカスは変えません
